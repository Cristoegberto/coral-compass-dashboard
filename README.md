6# Coral Compass: Scuba Destination Explorer
An interactive Tableau dashboard that compares scuba diving destinations around the world based on factors like affordability, accessibility, marine biodiversity, and unique diving experiences.

**Live Dashboard:** 
https://public.tableau.com/views/DiveDashboard-CoralCompass/Dashboard1

## About This Project

I created this project from the ground up as part of my data analytics portfolio. Instead of starting with a pre-built dataset, I researched scuba diving destinations, identified the factors I wanted to compare, and built the dataset myself in Excel before developing the Tableau dashboard.
After collecting and organizing the information, I designed an interactive dashboard that allows users to explore the information of the destinations by selecting either a location on the map or a dive category. The dashboard updates dynamically to make comparing destinations simple and intuitive based on affordability accessibility, marine biodiversity, and unique diving experience.

## The Problem

Planning a scuba diving trip usually means comparing information from multiple websites. Cost, accessibility, marine life, and the type of diving experience all influence where someone chooses to travel.
This dashboard brings those factors together in one place, making it easier to compare destinations side by side.

 ## Data Collection
 
Unlike many portfolio projects that begin with a pre-existing dataset, this project required creating the dataset from scratch. Information on dive destinations was researched, organized, and standardized before being imported into Tableau.
The dataset includes destination characteristics such as affordability, accessibility, marine biodiversity, and notable diving experiences to support meaningful comparisons across locations.

## What I Learned

Building this dashboard taught me much more than creating charts. I learned how important dashboard layout, user interaction, and clear design are when presenting information.
One of the biggest challenges was configuring Tableau dashboard actions so that selections updated the correct visualizations while still allowing users to easily reset the dashboard and continue exploring.
